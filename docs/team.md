# Команда проекта Pocket Spellbook

Руководитель проекта: `project-manager` (администратор репозиториев и доски).

Роли исполнителей условные. Все коммиты выполняет один автор; исполнитель виден по ветке, описанию pull request'а и полям доски GitHub Projects.

| Отдел | Руководитель | Сотрудник | Репозитории |
| --- | --- | --- | --- |
| Frontend | `frontend-lead` | `frontend-dev1` | pocket-spellbook |
| Backend | `backend-lead` | `backend-dev1` | pocket-spellbook-server |
| AI | `ai-lead` | `ai-dev1` | pocket-spellbook-ai |
| QA | `qa-lead` | `qa-dev1` | все три |
| DevOps | `devops-lead` | `devops-dev1` | все три |

Ветка исполнителя называется так же, как роль: `frontend-dev1`, `qa-lead` и так далее.
